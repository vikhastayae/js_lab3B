# Справочник пользователей

Веб-приложение на HTML, CSS и обычном JavaScript для загрузки пользователей и просмотра их публикаций из JSONPlaceholder.

## Запуск

Откройте `index.html` в современном браузере. Для запросов к API необходимо подключение к интернету.

## Проверка

- «Загрузить пользователей» отправляет GET-запрос к `/users`, проверяет HTTP-ответ и выводит имя, email и город каждого пользователя.
- Поиск фильтрует уже загруженный список по имени без учета регистра. Например, `Leanne` оставляет подходящие записи; для неизвестного имени появляется «Пользователи не найдены».
- «Показать публикации» отправляет GET-запрос к `/posts?userId=ID` для выбранного пользователя и показывает первые три записи с заголовками и текстами.
- Во время каждого запроса появляется «Загрузка...». Кнопка загрузки пользователей и кнопки публикаций блокируются и снова включаются после ответа.
- При сетевой или HTTP-ошибке выводится сообщение; после исправления причины запрос можно повторить. Для проверки HTTP-ошибки временно измените `usersUrl` в `app.js` на `https://jsonplaceholder.typicode.com/userz`, затем восстановите правильный адрес.

## Файлы

- `index.html` — разметка справочника.
- `style.css` — оформление страницы и карточек.
- `app.js` — загрузка данных, поиск и обработка событий.
